# 손글씨 숫자 인식기 (PyTorch MNIST CNN)

마우스로 숫자를 그리면 합성곱 신경망(CNN)이 0~9 중 어떤 숫자인지 실시간으로 인식하는 프로그램입니다.
MNIST 데이터셋으로 학습했으며, 테스트 정확도는 **99.48%** 입니다.

## 주요 기능

- 그림판에 숫자를 그리면 획을 뗄 때마다 자동으로 인식
- 예측 숫자와 확신도 표시
- 0~9 각 숫자의 확률을 막대그래프로 표시
- 모델에 실제로 들어가는 28x28 입력 이미지 미리보기
- `지우기` 버튼 또는 `Esc` 키로 그림판 초기화

## 프로젝트 구조

```
desktop_version/
├── model.py       # CNN 모델 정의
├── train.py       # MNIST 학습 및 가중치 저장
├── app.py         # tkinter 그림판 + 실시간 인식 프로그램
├── make_icon.py   # 아이콘(icon.ico) 생성
├── create_shortcut.ps1  # 바탕 화면 바로가기 생성
├── icon.ico       # 앱·바로가기 아이콘
├── mnist_cnn.pt   # 학습된 가중치 (train.py 실행 시 생성)
├── data/          # MNIST 데이터셋 (train.py 실행 시 자동 다운로드)
└── export_web.py  # 웹 버전(../web_version)용 가중치·테스트 기준값 내보내기
```

## 설치

> 아래 명령은 모두 **desktop_version 폴더 안에서** 실행합니다. 웹 버전은 [../web_version](../web_version)을 보세요.

Python 3.10 이상이 필요합니다. (Python 3.14에서 확인)

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install torch torchvision pillow
```

> tkinter는 Windows용 Python에 기본으로 들어 있습니다.
> NVIDIA GPU를 쓰려면 [PyTorch 공식 설치 페이지](https://pytorch.org/get-started/locally/)에서 CUDA 버전을 골라 설치하세요.
> 코드가 GPU를 자동으로 감지해서 사용합니다.

확인한 패키지 버전: torch 2.14.0, torchvision 0.29.0, Pillow 12.3.0, numpy 2.5.3

## 사용법

### 1. 학습

```bash
.venv\Scripts\python.exe train.py
```

- 처음 실행하면 MNIST 데이터를 `data/` 폴더에 내려받습니다.
- 에폭마다 학습·테스트 손실과 정확도를 출력하고, 테스트 정확도가 가장 높을 때의 가중치를 `mnist_cnn.pt`로 저장합니다.
- CPU 기준으로 에폭당 약 50초, 전체 약 7분 걸립니다.

### 2. 손글씨 인식 프로그램 실행

```bash
.venv\Scripts\python.exe app.py
```

검은 그림판에 숫자 **하나**를 크게 그리면 오른쪽에 결과가 나타납니다.

### 3. 바탕 화면 바로가기 만들기 (선택)

```bash
powershell -ExecutionPolicy Bypass -File create_shortcut.ps1
```

바탕 화면에 **손글씨 숫자 인식기** 바로가기가 생깁니다.

- 더블 클릭하면 검은 콘솔 창 없이 앱만 뜹니다. (`pythonw.exe`로 실행)
- 바로가기를 오른쪽 클릭하고 **작업 표시줄에 고정**을 누르면 작업 표시줄에 고정됩니다.
  (Windows 11에서는 **추가 옵션 표시**를 먼저 눌러야 할 수 있습니다.)
- 앱과 바로가기에 같은 AppUserModelID가 들어 있어서, 고정한 아이콘과 실행 중인 창이 하나로 묶입니다.
- 아이콘을 바꾸려면 `make_icon.py`를 고쳐 실행한 뒤 바로가기를 다시 만드세요.
- 프로젝트 폴더를 옮기면 바로가기가 옛 경로를 가리키므로 스크립트를 다시 실행해야 합니다.
- 저장소를 web_version/desktop_version으로 나눈 뒤에는 바로가기를 한 번 다시 만들어야 합니다.

## 모델 구조

| 단계 | 구성 | 출력 크기 |
|---|---|---|
| 입력 | 흑백 이미지 | 1 × 28 × 28 |
| 합성곱 블록 1 | Conv(3×3, 32) → BN → ReLU → Conv(3×3, 32) → BN → ReLU → MaxPool → Dropout(0.25) | 32 × 14 × 14 |
| 합성곱 블록 2 | Conv(3×3, 64) → BN → ReLU → Conv(3×3, 64) → BN → ReLU → MaxPool → Dropout(0.25) | 64 × 7 × 7 |
| 분류기 | Flatten → Linear(3136, 128) → ReLU → Dropout(0.5) → Linear(128, 10) | 10 |

### 학습 설정

| 항목 | 값 |
|---|---|
| 에폭 | 8 |
| 배치 크기 | 128 |
| 최적화기 | Adam (학습률 0.001) |
| 학습률 스케줄러 | CosineAnnealingLR |
| 데이터 증강 | 회전 ±10°, 이동 ±10%, 확대·축소 0.9~1.1배 |

데이터 증강은 사람이 직접 그린 숫자처럼 기울어지거나 위치가 조금씩 다른 입력에도 잘 동작하게 해 줍니다.

## 손글씨 전처리 방식

그림판(280×280)에 그린 숫자는 크기와 위치가 제각각입니다. 그래서 MNIST 데이터를 만든 방식과 똑같이 변환한 뒤 모델에 넣습니다.

1. 숫자가 그려진 영역만 잘라냅니다.
2. 가로세로 비율을 유지하며 긴 변이 20픽셀이 되도록 줄입니다.
3. 28×28 검은 배경의 가운데에 붙입니다.
4. 무게중심이 이미지 중앙(14, 14)에 오도록 옮깁니다.
5. 학습 때와 같은 평균(0.1307)과 표준편차(0.3081)로 정규화합니다.

MNIST 테스트 이미지 500장을 그림판 크기로 키우고 위치를 치우치게 넣어 이 과정을 거쳤을 때 498장(99.6%)을 맞혔습니다.

## 잘 인식되게 쓰는 요령

- 숫자는 한 번에 **하나만** 그리세요.
- 그림판을 적당히 채울 만큼 크게 그리세요.
- 인식이 이상하면 오른쪽 **모델 입력(28x28)** 미리보기로 모델이 무엇을 보고 있는지 확인해 보세요.
